# HEM-7271T 血圧フォト記録 v17

V17では、V16で不足していた2点を修正しました。

## 変更点
- 青枠をドラッグして移動可能
- 青枠右下の赤丸をドラッグして幅・高さを変更可能
- 数字1個が枠内にほぼ全部入るように調整可能
- 認識結果は `12? / ?1 / 8?` のように部分表示
- 全桁が認識できた項目だけ入力欄へ自動入力
- 1桁でも不確かな項目は誤入力防止のため自動入力しない
- V16の小さすぎる保存枠を引き継がないよう、プリセット保存キーをV17用に更新

## 初回手順
1. LCD四隅を合わせる
2. 液晶を補正
3. 青枠を数字1個ずつに合わせる
4. 必要なら右下の赤丸で枠を大きくする
5. 桁位置を保存
6. HEM-7271T専用解析

GitHub Pagesでは4ファイルを上書きしてください。
