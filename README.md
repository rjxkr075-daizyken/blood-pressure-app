# HEM-7271T 血圧フォト記録 v19

V19では、V18の「校正画像が縦に細すぎる」問題を修正しています。

## 主な変更
- SYS / DIA / PULSE の校正画面を縦方向にも大幅拡大
- 数字全体と上下余白まで見える範囲を表示
- `object-fit: contain` で数字を潰さず表示
- 校正画面の表示範囲と、保存される桁位置の座標系を一致
- 青枠は移動可能
- 右下の赤丸で幅・高さを変更可能
- 認識時は保存した青枠をほぼそのまま使用
- 内部の自動切り直しを最小限に抑制
- 部分認識は `1?? / ?1 / 8?` のように表示
- 全桁そろった項目だけ入力欄へ自動入力
- V18の保存枠を引き継がないようV19用プリセットキーへ変更

## 初回手順
1. 写真を選択
2. LCD四隅を合わせる
3. 液晶を補正
4. SYS / DIA / PULSE の大きな校正画面で、各数字1個が完全に青枠内へ入るよう調整
5. 桁位置を保存
6. HEM-7271T専用解析

GitHub Pagesでは4ファイルを上書きしてください。
