# HEM-7271T 血圧フォト記録 v14

V14では、1桁ずつの青枠調整を廃止しました。

## 認識フロー
1. LCDの四隅だけ合わせる
2. SYS / DIA / PULSE の3行を自動で切り出す
3. 各行の縦方向投影から桁間の空白を探す
4. SYSを3桁、DIAを2桁、PULSEを2桁に自動分割
5. 各数字を正規化
6. 背景差分 + 7セグパターンで判定

## 狙い
ユーザーが数字ごとの枠を毎回合わせる必要をなくし、
LCD四隅だけの操作で読める形に近づけます。
