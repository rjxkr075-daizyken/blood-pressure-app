# HEM-7271T 血圧フォト記録 V27

V27はV26の自動桁位置検出を維持し、認識時の切り出しだけを変更した版です。

## 維持
- LCD四隅補正
- 7個の青枠
- 桁位置の自動検出
- 手動修正
- V23/V25系の濃いLCDセグメント抽出
- 学習サンプルなし

## V27の変更
青枠そのものを動かしたり、画像内容を見て自動トリミングしたりしません。
認識時だけ各青枠の内側を固定割合で使用します。

- 左 8%
- 右 8%
- 上 6%
- 下 10%

目的は、隣接数字やLCD下端・外周が特徴量へ混ざるのを減らすことです。

ログには `inner=L0.08,R0.08,T0.06,B0.10` と表示されます。
