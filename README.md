# HEM-7271T 血圧フォト記録 v10

V10では、二値化とテンプレート照合をやめています。

## 認識方式
- LCDの4点補正
- 各数字枠を手動で位置合わせ
- 7つのセグメント領域ごとに平均輝度を計算
- セグメント周囲の局所背景との明暗差を測定
- 細いモアレではなく、太い液晶セグメントの局所コントラストを優先
- SYS / DIA / PULSE の妥当範囲と SYS>DIA を使って候補を絞る

## 調整
「セグメント判定感度」を変えると、点灯判定のしきい値を変更できます。
ログには各桁の7bitパターンと7つの局所コントラスト値が表示されます。
