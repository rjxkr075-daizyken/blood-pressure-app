# HEM-7271T 血圧フォト記録 v15

V15では、HEM-7271T専用の固定レイアウトを使います。

## 認識フロー
1. LCD四隅だけ合わせる
2. 900×700へ正規化
3. HEM-7271T専用のSYS3桁 / DIA2桁 / PULSE2桁の基準位置で直接切り出す
4. 各固定枠の中だけ±10%程度の微調整を自動探索
5. 各数字を84×150へ正規化
6. 背景差分 + 7セグパターンで判定

## 狙い
V14では桁境界を自動探索したため、「1」のような細い数字の左右余白を
桁間と誤認しやすい問題がありました。
V15では機種専用座標を使い、桁境界の探索自体をやめています。
