# HEM-7271T 血圧フォト記録 V31

V31は位置検出方式を変更した版です。

## 自動処理
1. LCD四隅を自動検出
2. 射影補正でLCDを正面化
3. SYS / DIA / PULSE の3つの広い探索エリアだけを見る
4. 各探索エリア内で「数字群」を先に検出
5. 数字群の内部だけを SYS=3桁 / DIA=2桁 / PULSE=2桁 に分割
6. 7個の青枠を生成

## 除外
- 左側の「最高血圧・最低血圧・脈拍」等の印刷文字
- 右側の圧力バー

## 認識器
- SYS/DIA: V27方式を維持
- PULSE: V28方式を維持
- 学習サンプルなし

V31の目的は、認識器を変更することではなく、
正しい数字を正しい位置で切り出すことです。
