# HEM-7271T 血圧フォト記録 v6

## v6の変更
- 数字の青枠をv5より大きめに初期設定
- 青枠をドラッグして移動可能
- 各青枠の右下の赤い丸をドラッグして縦横サイズを変更可能
- 調整した位置とサイズを端末に保存可能
- v6専用の保存領域に変更し、v5の古い枠設定が自動適用されないようにした

## 調整の目安
数字の線ギリギリではなく、上下左右に少し余白を含めて1桁全体が青枠に入るようにしてください。

1. LCD四隅を合わせる
2. 「液晶を補正」
3. 青枠を各数字に移動
4. 右下の赤丸で枠を拡大・縮小
5. 「この枠で読み取る」
6. 正しく読めたら「枠位置を保存」
