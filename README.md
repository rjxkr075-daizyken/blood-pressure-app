# HEM-7271T 血圧フォト記録 V33

V33では桁位置検出方式を変更しました。

## V33の方式
1. LCD四隅を補正
2. SYS / DIA / PULSE の3行を広めに取得
3. 各行で、x方向ごとの黒画素量を集計
4. 数字と数字の間にある「縦の空白の谷」を検出
5. SYS=3セル、DIA=2セル、PULSE=2セルに分割
6. 各セル内だけで黒い数字本体の外接矩形を再取得
7. その外接矩形を青枠として表示
8. 認識器は従来方式を利用

## V32からの変更
- 7セグメント同士の連結・クラスタリングを廃止
- 「2」が複数セグメントに分裂しても問題ない
- 隣の桁と同じ数字を二重取得しにくい
- 細い「1」も、桁間の空白で独立セルとして分離
- 左印刷文字・右圧力バーは探索範囲外
