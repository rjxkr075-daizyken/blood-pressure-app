# HEM-7271T 血圧フォト記録 V32

V32では青枠検出方式を「数字本体中心方式」に変更しました。

処理:
1. LCD四隅を自動検出して射影補正
2. LCD数字領域内の濃い7セグメント形状を抽出
3. 連結成分を取得
4. x方向の重なり・近さから同じ数字のセグメントを統合
5. 各数字本体の外接矩形を作成
6. 位置関係から SYS 3桁 / DIA 2桁 / PULSE 2桁へ割り当て
7. 外接矩形を少し拡大して青枠として表示

重要:
- 行を単純に3等分/2等分しない
- 「1」と「8」で枠幅を同じにしない
- 左側の印刷文字を除外
- 右側の圧力バーを除外
- 圧力バーの濃淡を基準にしない
- 学習サンプルは使わない

認識器:
- SYS/DIA: V27方式
- PULSE: V28方式
