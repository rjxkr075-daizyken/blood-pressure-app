# HEM-7271T 血圧フォト記録 v23

V23では、V22までに安定してきた次の部分は変更していません。

- LCD四隅補正
- LCD全体1枚での7桁青枠校正
- 青枠そのものを認識範囲として使う方式

## V23の変更点

認識前処理を変更しました。

1. 各桁を青枠で切り出す
2. 局所背景を推定
3. 絶対的な暗さと局所コントラストの両方を満たす画素だけ残す
4. 3×3近傍で孤立ノイズを除去
5. 小さすぎる連結成分を削除
6. 残った濃いLCDセグメントから広い7領域の相対強度を算出
7. 0〜9のセグメント構造と比較

## 採用しない方式

- 学習サンプルの蓄積
- 過去画像テンプレート照合
- 画像ごとの手動教師データ
- 固定7点だけを見る判定

V22で背景やぼけまで黒画素として拾っていた問題を減らすのがV23の目的です。
