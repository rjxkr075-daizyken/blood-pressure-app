# HEM-7271T 血圧フォト記録 v4

v3で全桁が `1111111` になった結果を受けて、判定方法を変更しました。

## v4の変更
- 画像全体の「暗さ」を基準にする方式を廃止
- 7セグ各部について、その部分と直近の周囲との明るさの差（局所コントラスト）を計算
- LCD背景・影・露出の影響を受けにくい判定へ変更
- 感度スライダーを追加
- デバッグ表示に各セグメントのコントラスト値を表示
- PWAキャッシュをv4へ更新

## テスト
最初は感度 0 で読み取ってください。

全桁が 1111111 の場合:
感度を +10、+20 と上げて再読み取り。

全桁が 0000000 の場合:
感度を -10、-20 と下げて再読み取り。

うまく読めない場合は画面下の
SYS bits / DIA bits / PULSE bits
をそのまま共有してください。
