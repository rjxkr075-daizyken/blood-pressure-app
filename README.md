# HEM-7271T 血圧フォト記録 v8

V8では、一般的な数字テンプレートだけでなく、実際のHEM-7271T写真から数字の見え方を学習できるようにしました。

## 使い方
1. 写真を選択
2. LCD四隅を4点指定
3. 液晶を補正
4. 数字枠を合わせる
5. 写真を見て正しいSYS/DIA/PULSEを手入力
6. 「この写真から学習」
7. 次回以降は「読み取る」

## 学習
- 各数字 0〜9 ごとに最大20枚の正規化画像を端末内に保存
- 判定時は学習済み実機テンプレートを優先
- 未学習の数字は汎用7セグテンプレートへフォールバック
- 学習データは「学習データ削除」でリセット可能

## 目的
複数の実機写真を蓄積するほど、その血圧計固有のLCD表示・撮影環境に合わせて認識精度を改善する実験版です。
