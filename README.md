# 血圧フォト記録

血圧計の写真から数値候補をOCRで読み取り、本人が確認後に保存するスマホ向けPWA試作版です。

## 記録項目
- 日付
- 収縮期血圧（上）
- 拡張期血圧（下）
- 脈拍
- メモ

## 写真入力
1. 「血圧計を撮影 / 写真を選択」
2. 血圧計の表示部をなるべく真正面・明るく・大きく撮る
3. 「写真から読み取る」
4. 入力された数値を必ず実物写真と照合
5. 「確認して保存」

OCRには Tesseract.js を使用します。
初回読み込み時などはインターネット接続が必要です。

## 注意
OCRは医療機器の数値を誤認識する可能性があります。
この試作版では、OCR結果を自動確定せず、ユーザー確認を必須にしています。
