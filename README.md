# HEM-7271T 血圧フォト記録 v21

V21は桁位置プリセットUIを作り直した版です。

## 重要な変更
- SYS / DIA / PULSE ごとのズーム切り出し画面を完全に削除。
- 補正後のLCD全体を1枚だけ表示。
- そのLCD全体画像の上に7個の青枠を直接表示。
- 青枠は自由に移動可能。
- 右下の赤丸で縦横とも自由に拡大縮小可能。
- ズーム領域による移動・サイズ制限なし。
- 校正画面の青枠座標と認識時の切り出し座標は同一。
- V19/V20の保存プリセットは使用せずV21用に新規保存。

## 使い方
1. 写真を選択または撮影。
2. 4点をLCD四隅へ合わせる。
3. 「液晶を補正」。
4. LCD全体1枚の上で7個の青枠を数字1個ずつに合わせる。
5. 数字全体＋少しの余白が入るまで赤丸で拡大。
6. 「桁位置を保存」。
7. 「HEM-7271T専用解析」。
