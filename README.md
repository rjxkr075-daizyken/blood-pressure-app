# HEM-7271T 血圧フォト記録 v12.1

V12では、数字画像そのものを二値化せず、ぼかした背景画像との差分を使います。

## 変更点
- 各数字画像をグレースケール化
- 強めのぼかしでLCD背景を推定
- 元画像との差分から太い液晶セグメントを強調
- 7つのセグメント領域の差分強度を比較
- 0〜9のパターンとの誤差を計算
- 1位と2位の候補差が小さい場合は `?`
- 血圧としてありそうだからという理由で数値補完しない
