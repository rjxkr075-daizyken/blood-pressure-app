# HEM-7271T 血圧フォト記録 V24

V24はV23修正版2を基礎にしています。

## 維持したもの
- LCD四隅補正
- LCD全体1枚での7個の青枠校正
- 青枠を認識範囲として使用
- 濃いLCDセグメント抽出
- 学習サンプルを使わない方針
- 実行状況・エラー表示

## V24の変更
1. 青枠で切り出した後、濃いLCDセグメントの外接範囲を検出
2. 隣の数字へ飛びつかない範囲で数字本体へ自動トリミング
3. 数字本体を100×170へ正規化
4. 形状判定
5. V23で誤認した 1 / 7 / 0 の判別を強化
6. 0と8の区別では中央セグメントの相対強度を重視

今回のテスト基準画像では、正解は 121 / 71 / 80 です。
