# HEM-7271T 血圧フォト記録 V34

V34ではV33の失敗原因だった「探索範囲が広すぎる」問題を修正しています。

## V34の桁検出
1. LCD四隅補正
2. SYS / DIA / PULSE の各行を取得
3. 各行で黒画素の横方向分布を解析
4. 数字が実際に存在する「数字帯」の左端・右端を先に検出
5. 左側の印刷文字・LCD余白・右側の圧力バーを数字帯から除外
6. 数字帯の内部だけで桁間の縦の空白を探索
7. SYS=3桁、DIA=2桁、PULSE=2桁に分割
8. 各セル内の数字本体へ青枠を再トリミング

認識器自体は従来のV27/V28系を維持しています。
