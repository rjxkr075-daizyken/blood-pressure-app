# HEM-7271T 血圧フォト記録 V28

V28はV27を基礎にしています。

## 完全維持
- LCD四隅補正
- 桁位置の自動検出
- 7個の青枠
- SYSのV27判定
- DIAのV27判定
- 学習サンプルなし

## PULSEだけ変更
SYS/DIAは触らず、PULSEの2桁だけ専用認識に分離しました。

PULSE用固定インナー領域:
- 左 6%
- 右 6%
- 上 4%
- 下 20%

PULSEは120×180に拡大してから解析します。

0と8については、中央セグメント単体ではなく
外周6セグメントの平均と中央セグメントの比率も使って判定します。

今回の基準画像:
- SYS 121
- DIA 71
- PULSE 80
