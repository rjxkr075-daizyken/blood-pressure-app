# HEM-7271T 血圧フォト記録 v20

V20の変更点

- 桁位置プリセットの3段ズーム表示を廃止。
- 補正後のLCD全体を、引いた1枚の画像として表示。
- SYS 3桁 / DIA 2桁 / PULSE 2桁の7個の青枠を同じ画像上で直接調整。
- 青枠は移動可能。右下の赤丸で縦横とも拡大縮小可能。
- 画面上の青枠座標を、そのまま認識時の切り出し座標として使用。
- V19以前の桁位置プリセットは引き継がず、V20用として新規保存。
- 撮影済み写真の選択にも対応。

使い方

1. 「今撮影する」または「写真から選ぶ」
2. 4つの丸をLCD四隅へ合わせる
3. 「液晶を補正」
4. LCD全体画像上の7個の青枠を数字全体が入るよう調整
5. 「桁位置を保存」
6. 「HEM-7271T専用解析」
