# HEM-7271T 血圧フォト記録 v3

OCRをやめ、OMRON HEM-7271Tの7セグ液晶を直接判定する実験版です。

## v3の変更点
- Tesseract OCRを完全に削除
- 7本の液晶セグメントのON/OFFから数字を判定
- SYS / DIA / PULSEを個別認識
- 写真の濃さに合わせた補正スライダー
- 認識したビット列を画面に表示して調整可能
- PWAキャッシュをv3へ更新

## 撮影条件
今回提供された実機写真を基準に調整しています。
- 本体を縦向き
- できるだけ真正面
- 本体が写真の大部分を占める
- 画面に強い反射が入らない

撮影位置が大きく変わる場合、次版では画面の四隅指定や自動位置補正を追加する予定です。
