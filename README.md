# HEM-7271T 血圧フォト記録 v13

V13では、青い数字枠の中から実際の数字本体を自動検出し、
上下左右の余白を切り詰めてから同じ比率へ正規化します。

## 主な変更
- 写真ライブラリから既存写真を選択可能
- LCD四隅補正
- 数字枠を手動で大まかに合わせる
- 枠内の差分画像から数字本体の境界を自動検出
- 数字本体を切り詰め
- 全桁を同じ 84×150 の比率へ正規化
- 正規化後に背景差分と7セグ照合
- 候補差が小さい桁は `?`
- 血圧として自然という理由だけでは補完しない

## 狙い
V12では、同じ数字でも青枠内で左右・上下に寄ると
7セグ判定領域との位置関係がずれていました。
V13では数字本体そのものを中央へ正規化し、このズレを減らします。
