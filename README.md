# HEM-7271T 血圧フォト記録 v9

v9は、単純テンプレート照合から一段進めた認識版です。

## v9の変更
- 数字枠内の画像を大幅縮小してモアレを抑制
- 数字本体を自動的に切り詰め
- 全桁を同じサイズへ正規化
- 実機学習テンプレートとの類似度
- 7セグ形状との類似度
- SYS / DIA / PULSEの範囲と SYS>DIA の整合性
を組み合わせて最終候補を選びます。

## 使い方
1. 写真を選択
2. LCD四隅を合わせる
3. 液晶を補正
4. 数字枠を合わせる
5. 読み取る
6. 誤認識なら正しい上・下・脈拍を入力
7. この写真から学習

学習データは端末のlocalStorageに保存されます。
