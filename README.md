# HEM-7271T 血圧フォト記録 v11

V11では、固定した7点を読む方式をやめ、数字枠の中で実際に暗い横棒・縦棒の位置を自動探索します。

## 主な変更
- 上・中央・下の横棒を広い範囲から自動探索
- 左上・右上・左下・右下の縦棒も広い範囲から自動探索
- 各数字ごとにコントラスト分布から判定しきい値を自動設定
- 低信頼度の数字は `?`
- 血圧としてありそうだから、という理由だけで数値を補完しない
- 誤入力防止を優先
