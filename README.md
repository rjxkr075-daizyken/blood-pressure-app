# HEM-7271T 血圧フォト記録 v7

V7では固定した7セグ検査点を廃止し、数字の形そのものを比較する方式に変更しました。

## 認識手順
1. LCDの四隅を4点指定
2. LCDを正規化
3. 各数字枠を手動調整
4. 枠内から暗い数字部分を自動抽出
5. 数字本体の外接範囲まで自動クロップ
6. 90×150へ正規化
7. 0〜9の7セグ形状テンプレートと全体形状を比較
8. 最も近い数字を候補として採用

## V7の狙い
- 数字位置が少しズレても対応
- 1のような細い数字も数字本体に合わせて正規化
- セグメントの固定点ではなく全体形状で評価
- 認識候補上位3つとスコアを画面に表示
