# HEM-7271T 血圧フォト記録 V29

V29は「位置決めの自動化」を中心に変更した版です。

## 写真を選ぶと自動で行うこと
1. LCD四隅を画像から自動検出
2. LCDを自動補正
3. HEM-7271T専用の基準座標で7桁を配置
4. 各桁を数ピクセル相当だけ局所補正

通常は4点も7個の青枠も手で合わせる必要がありません。

## 手動操作は残しています
LCD自動検出が失敗した場合は4点を手動修正できます。
7桁の青枠も確認・手動修正・保存が可能です。

## 認識ロジック
- SYS/DIAはV27方式
- PULSEはV28方式
- 学習サンプルは使用しません

V28でPULSE 80まで読めるようになったため、
V29では認識ロジックを大きく変えず、位置ズレの改善を優先しています。
